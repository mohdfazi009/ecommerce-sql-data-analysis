# E-Commerce SQL Data Analysis

## 📌 Project Overview

This project analyzes an e-commerce dataset using MySQL.

The goal is to understand customer behavior, product performance, order trends, sales performance, and overall business insights using SQL.

## 🛠️ Tools Used

- MySQL
- MySQL Workbench
- SQL

## 📊 Analysis Performed

### Customer Analysis
- Total customers
- Customer spending
- Repeat customers
- Top customers
- Customer order behavior

### Product Analysis
- Product sales
- Units sold
- Category performance
- Product pricing
- Inventory analysis
- Best-selling products

### Order Analysis
- Total orders
- Order status analysis
- Cancellation rate
- Order value
- Orders per customer
- High-value orders

### Time Analysis
- Monthly orders
- Monthly sales
- Orders by weekday
- Busiest dates
- Sales by weekday
- Order trends

### Advanced SQL
- Subqueries
- CTEs
- Window Functions
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- LAG()
- LEAD()
- SUM() OVER()
- COUNT() OVER()
- AVG() OVER()
- MIN() OVER()
- MAX() OVER()

## 💡 Business Insights

The analysis helps identify:

- High-value customers
- Best-performing products
- Best-performing categories
- Order cancellation patterns
- Sales contribution
- Inventory opportunities
- Customer purchasing behavior

## 📁 Project File

- `ecommerce_sql_project.sql` — Complete SQL database setup, data, analysis queries, and business insights.
